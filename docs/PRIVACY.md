# 隐私与本地数据

AI Prompt Studio 是纯静态前端：没有账号、后台数据库、遥测或生图接口，不请求 API 密钥。草稿、收藏夹、组合、个人词条、主题及排序设置写入当前浏览器的 LocalStorage。自定义输入不会由应用发送给 Danbooru、NovelAI 或翻译服务。

打开网页时，浏览器会从提供此站点的服务器加载代码、许可及本地词库文件。托管平台仍可能按其政策记录 IP、访问时间和资源请求。本项目的“本地保存”不表示整个网页不访问网络，也不包括浏览器扩展、操作系统或托管平台自身的行为。

- 复制会把 Prompt 写入系统剪贴板；下载备份会创建由你保存的 JSON 文件。
- 备份包含草稿、收藏、组合、个人词典和设置，分享前请检查私人内容。
- 清除站点数据、卸载浏览器或使用隐私窗口，可能丢失数据。请定期通过“备份恢复”导出。
- LocalStorage 按“协议、域名、端口”隔离，不按网页子路径隔离。迁移域名或从本地切换在线站点后，需要手动导出和恢复；同一域名下的本应用副本可能共享存储键。
- 浏览器存储没有加密，不适合存放密码、密钥或高度敏感资料。
- 剪贴板功能通常需要 HTTPS 或 localhost；离线使用请运行本地服务器，不要直接双击 HTML。

问题反馈请使用演示标签和去除私人内容的截图，不要直接附上完整浏览器资料或真实备份。
